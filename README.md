Для использования данной простой программы вам нужно установить следующие компоненты:
- Установить snakemake workflow. Для этого вам потребно:
  - Удостовериться, что у вас установлен визуальный пакет C++ 14 версии или выше. Если это не так, то вы:
    - Переходите по этой ссылке https://visualstudio.microsoft.com/ru/visual-cpp-build-tools/
    - Устанавливаете visual studio installer
    - Устанавливаете Visual Studio Build Tools 2026
  - Ввести в терминал: ```python -m pip install --upgrade --force-reinstall snakemake```
  - Как только программа установится, найти её в системе и внести в PATH. Для этого потребуется:
    - Убедиться в наличии вашего snakemake.exe по пути "C:\Users\<Ваше имя пользователя>\AppData\Local\Python\<Ваша папка pythoncore>"
    - Если наличие подтверждено, то открывете настройки windows, находите настройку "Изменение переменных среды текущего пользователя"
    - В верхней таблице, жмёте "Изменить"
    - В открывшей таблице жмёте "Создать" %>% "Обзор" и указываете путь к папке pythoncore.
  - Проверить правильность выполненных действий через ввод в терминал: ```snakemake --version```
- Установить на ваш компьютер саму папку проекта
- Перейти в необходимую папку проекта через ```cd <положение папки проекта>```
- Ввести snakemake
- Наслаждаться результатом.
